# Linux e2e capability matrix

This is the Linux appendix to the shared
[Security Test Tiers](../../docs/security-test-tiers.md). The Linux e2e suite
is split by privilege and kernel capability so local quickstart testing does
not depend on sudo or a developer-installed helper.

| Tier | Group | Script or command | Privilege model | Expected behavior |
| --- | --- | --- | --- | --- |
| 0/1 | Default security harness | `bash scripts/test_security_tier0.sh` | Non-root, no host mutation | Runs shared capability-planner tests and MXC fake executor/translation tests. Skips tests named with the `gated_` prefix so optional runtime dependencies are not hidden normal-test requirements. |
| 1 | Unprivileged standalone | `bash e2e/linux/test_sandbox.sh [axis]` | Non-root, no host mutation | Runs built `axis run` with generated policies. Verifies policy validation, workspace-only writes, block-mode socket denial, policy-aware seccomp, and timeout behavior. Missing kernel/resource support is reported as an explicit skip. |
| 1 | Unprivileged daemon | `bash e2e/linux/test_e2e_daemon.sh [axis]` | Non-root, no host mutation | Starts `axisd` with a throwaway socket and `XDG_DATA_HOME`. Verifies create, list, contained exec, destroy, timeout cleanup, and process-tree cleanup. Missing kernel/resource support is reported as an explicit skip. |
| 4 | Helper-gated proxy | `AXIS_RUN_PRIVILEGED_E2E=1 bash e2e/linux/test_netns_helper_launch.sh` | Ephemeral CI/container/VM with passwordless sudo | Builds `axis-netns-helper` from the current checkout, refuses to overwrite any preexisting helper, installs it setuid-root only inside the disposable runner, and removes it during cleanup. Runs the non-root helper launch proof, proves the MXC provider is refused on the helper path before launch, and runs a built `axis` proxy-mode proof with `auto` (which must select the native backend) and with `axis_native` for allowed CONNECT with tunneled bytes, denied CONNECT, and direct-bypass firewall denial. Set `AXIS_REQUIRE_BUILT_AXIS_PROXY_E2E=1` when a runner is expected to provide every proxy prerequisite. |
| 4 | Helper-gated bypass audit | `AXIS_RUN_PRIVILEGED_E2E=1 bash e2e/linux/test_netns_helper_launch.sh` | Same disposable runner, plus a usable `/dev/kmsg`; CI may install a root-owned copy of the locally built `axisd` with temporary `CAP_SYSLOG` and read-only DAC bypass capabilities | After the built `axis` proxy proof, enables netfilter log delivery from non-initial network namespaces with captured-state restoration, starts the throwaway `axisd` with a temporary socket and log directory, triggers a direct-bypass attempt from a proxy-mode sandbox, and verifies one structured audit record contains the matching sandbox id and rejected destination port. A root-owned seccomp launcher is installed beside the daemon without capabilities so MXC dependency resolution remains production-equivalent. Both temporary executables, the daemon capabilities, and the temporary netfilter setting are removed or restored during cleanup. Set `AXIS_REQUIRE_KMSG_AUDIT_E2E=1` when `/dev/kmsg` access is expected. |
| 2 | Bubblewrap-gated fallback | `AXIS_RUN_BWRAP_E2E=1 bash e2e/linux/test_bwrap_fallback.sh` | Non-root with safe `bwrap` on `PATH` | Builds `axis` and, on a runner where Landlock is unavailable, proves the built binary selects the bwrap fallback for workspace writes and block-mode network denial. On normal Landlock-capable runners, runs the crate-level gated bwrap fallback proof for mounts, network denial, and descriptor handling. Skips when the runner has no trusted bubblewrap executable. |
| 3 | MXC process runtime | `AXIS_RUN_MXC_PROCESS_E2E=1 bash e2e/linux/test_mxc_process_runtime.sh` | Non-root with safe `lxc-exec` or `AXIS_TEST_MXC_EXECUTOR`, `bwrap`, unprivileged user namespaces, `python3`, the MXC private-network tools (`slirp4netns`, `unshare`, `nsenter`, `iptables`/`ip6tables` and their `-restore` variants) with `/dev/net/tun`, and a built checkout | Builds the unprivileged `axis-seccomp-launcher` from the current checkout and runs the Rust real-runtime MXC process proofs for allow/block parity, filesystem behavior, environment secret stripping, output capture, cleanup, timeout cleanup, and private config-fd isolation. With `AXIS_REAL_MXC_PROXY_TESTS=1`, it also runs strict proxy reachability. With no gate, the script skips; with a gate set, missing dependencies fail. |
| 3 | MXC LXC smoke | `AXIS_RUN_MXC_LXC_E2E=1 bash e2e/linux/test_mxc_lxc_smoke.sh` | Non-root with safe `lxc-exec` or `AXIS_TEST_MXC_EXECUTOR`, configured LXC runtime/image inputs, and `python3` for config generation | Emits AXIS-style MXC LXC wire configs and proves command stdout, stderr with nonzero exit, readwrite filesystem behavior, and timeout for the selected distribution/release. Tune image selection with `AXIS_MXC_LXC_DISTRIBUTION` and `AXIS_MXC_LXC_RELEASE`. With no gate, the script skips; with a gate set, missing executor or runtime support fails. |
| 3 | Capability-gated kernel proofs | `AXIS_REAL_NETNS_TESTS=1`, `AXIS_REAL_CGROUP_TESTS=1`, or other targeted cargo tests | Non-root only when delegated kernel resources are available | Exercises native netns/cgroup behavior against the real kernel. These are not prerequisites for quickstart; missing capabilities must produce visible skips or failures, never false confidence. |
| 3 | MXC VM smoke | `AXIS_RUN_MXC_MICROVM_E2E=1 bash e2e/linux/test_mxc_vm_smoke.sh` or `AXIS_RUN_MXC_HYPERLIGHT_E2E=1 bash e2e/linux/test_mxc_vm_smoke.sh` | Non-root with safe `lxc-exec` or `AXIS_TEST_MXC_EXECUTOR`, KVM access, and matching MXC runtime artifacts | Emits AXIS-style MXC VM wire configs and proves command stdout, stderr with nonzero exit, readwrite filesystem behavior, and timeout for the selected VM backend. With no gate, the script skips. With a gate set, missing executor, KVM access, or runtime support is a failure because the runner declared those dependencies available. |
| 3 | MXC process/container benchmark | `AXIS_BENCH_MXC_BUBBLEWRAP=1 bash e2e/linux/bench_mxc_runtime.sh` or `AXIS_BENCH_MXC_LXC=1 bash e2e/linux/bench_mxc_runtime.sh` | Non-root with safe `lxc-exec` or `AXIS_TEST_MXC_EXECUTOR`, `/usr/bin/time`, `python3`, and backend-specific runtime inputs | Emits AXIS-style MXC Bubblewrap or LXC wire configs and reports JSON summaries for cold lifecycle, warm lifecycle distribution, max RSS, and concurrent density. Tune with `AXIS_MXC_RUNTIME_BENCH_RUNS`, `AXIS_MXC_RUNTIME_BENCH_DENSITY`, `AXIS_MXC_RUNTIME_BENCH_TIMEOUT_SECONDS`, and optionally write JSON with `AXIS_MXC_RUNTIME_BENCH_OUTPUT`. Reports metric gaps for teardown, descriptor count, and process count until the harness can collect those independently. With no gate, the script skips; with a gate set, missing dependencies fail. |
| 3 | MXC VM benchmark | `AXIS_BENCH_MXC_MICROVM=1 bash e2e/linux/bench_mxc_vm.sh` or `AXIS_BENCH_MXC_HYPERLIGHT=1 bash e2e/linux/bench_mxc_vm.sh` | Non-root with safe `lxc-exec` or `AXIS_TEST_MXC_EXECUTOR`, KVM access, `/usr/bin/time`, and matching MXC runtime artifacts | Emits AXIS-style MXC VM wire configs and reports JSON summaries for cold start, warm start distribution, max RSS, and concurrent density. Tune with `AXIS_MXC_VM_BENCH_RUNS`, `AXIS_MXC_VM_BENCH_DENSITY`, `AXIS_MXC_VM_BENCH_TIMEOUT_SECONDS`, and optionally write JSON with `AXIS_MXC_VM_BENCH_OUTPUT`. With no gate, the script skips; with a gate set, missing dependencies fail. |

The default local proof starts with the Tier 0/1 security harness and then uses
the unprivileged standalone plus daemon groups for built-binary behavior. Any
test that mutates `/usr`, requires setuid helper installation, changes firewall
state, assumes writable cgroups, or reads kernel logs must live in a gated group
and describe the missing prerequisite when skipped.
